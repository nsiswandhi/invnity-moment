# InVnity Moments

Fondasi aplikasi Next.js App Router untuk menyimpan dan merayakan momen berharga.

## Menjalankan lokal

Gunakan Node.js 22.x, salin `.env.example` menjadi `.env.local`, lalu isi variabel R2 dan `SESSION_SECRET` (minimal 32 karakter).

```bash
npm install
npm run dev
```

## Perintah pengujian

`npm run test:unit` · `npm run test:e2e` · `npm run lint` · `npm run typecheck` · `npm run test:load`
